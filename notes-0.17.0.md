## Collectify 0.17.0

Installs over your existing Collectify; your data is kept.

### Updates and the project site
- **Check for updates.** The ℹ️ About sheet now has an **Updates** section. *Check for updates* compares your installed version with the published release list; if there's a newer one, *Releases page* opens GitHub in your browser so you can download and install it over the app.
- **Checksum check.** On Android the app also computes the SHA-256 of its own installed APK and compares it with the checksum published for that version, so you can see whether your install matches the official file. (It only applies to an install made from the release file.)
- **Website.** Collectify now has a GitHub Pages site explaining the app, its goals and approach, with every release's SHA-256 listed: https://unaveragetech.github.io/collectify-app/

Tested on an Android emulator and a desktop browser, not on a physical phone.
