## Collectify 0.21.1 — the Wooden Pickaxe is free

Android `.apk` and iPhone/iPad `.ipa`, same version, same change.

- **New players start with the Wooden Pickaxe, already equipped.** No more spending 40 coins on a pickaxe before you can mine; you keep your starting 150 coins for your first block.
- **Existing players who never bought one get it automatically** the next time they open the Treasure Box (their coins are untouched).
- The Treasure Box welcome text now says you start with a Wooden Pickaxe.
- Also fixed: since 0.19.1 the Forge's "Buy a Wooden Pickaxe" button was malformed and did nothing, which could leave a brand-new player unable to start mining. The button is repaired, and it no longer shows because the pickaxe is free.

### Tested
Checked in a desktop browser: a saved game with no pickaxe loads with the Wooden Pickaxe owned, the Forge shows no buy button, and a fresh game defaults to owning it. Not retested on a phone.
