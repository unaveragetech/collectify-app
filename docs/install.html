Install

Install Collectify

Collectify isn't in the Play Store or App Store, so you install the file directly. That's normal for hobby apps, it's reversible, and it takes about two minutes on Android and ten the first time on iPhone.

You need

Android 8.0 or newer, about 450 MB of free space (the app is ~90 MB; on first launch it unpacks the card catalog), and a way to open files from your browser's downloads.

Install the APK

Works on every Android phone and tablet. No computer needed.

1

Download the file

Tap Download Android above, or get Collectify-vX.Y.Z.apk from the changelog or the GitHub releases page. Use your phone's browser. If it warns "this type of file can harm your device", tap Download anyway: that message appears for every APK from outside the Play Store.

2

Open it

When the download finishes, tap Open in the browser's download bar, or open the Downloads app (Files → Downloads) and tap the APK.

3

Allow installs from this source (first time only)

Android will say "For your security, your phone isn't allowed to install unknown apps from this source." Tap Settings, switch on Allow from this source for the browser or file manager you used, then press back.

  • Samsung and some others: Settings → Apps → your browser → Install unknown apps.
  • You can switch the permission off again afterwards.
4

Tap Install

If Google Play Protect says "App blocked to protect your device" or "Unknown developer", tap More details → Install anyway. It shows this for any app that isn't from the Play Store.

5

Open Collectify

The first launch takes a few seconds while it unpacks the card catalog. Camera permission is asked the first time you scan a card, and notification permission only if you turn on reminders.

Updating

Updates install over the top and keep everything: binders, wishlist, grades, trades and game progress.

1

Check for a new version

In the app tap the ℹ️ button, then Check for updates. It tells you if there is a newer version and checks that your installed copy matches the published checksum.

2

Download and open the new APK

Follow steps 1, 2 and 4 above. It says Update instead of Install. Never uninstall first: that deletes your collection.

If something goes wrong (Android)

"App not installed" or "There was a problem parsing the package"

The download is usually incomplete. Delete it and download again over a stable connection, then compare the SHA-256 (see below). Make sure there's room: the install needs a few hundred MB free.

"App not installed as package conflicts with an existing package"

You have a copy of Collectify signed with a different key (a debug or test build). Back up anything you need, uninstall that copy, then install this one. Every official release from 0.11.1 on uses the same key, so normal updates never hit this.

I can't find "Install unknown apps"

Search for unknown apps in Settings. On Android 8+ the permission is per app (your browser or file manager), not global.

The first launch is stuck on the logo

Give it up to a minute on older phones; it's copying the catalog. If it doesn't move, close the app from recents and open it again. Still stuck? Check you have a few hundred MB free.

The camera doesn't work

Settings → Apps → Collectify → Permissions → Camera → Allow. Cards scan best in even light with the card filling most of the frame.

Read this first: how iPhone installs work

Apple only lets apps from the App Store run, apart from ones signed with your own Apple ID. Collectify's .ipa is deliberately unsigned: a sideloading tool signs it for you, on your computer, with your Apple ID. Nothing is installed from us that you didn't sign yourself.

With a free Apple ID the signature lasts 7 days. After that the app stops opening until you "refresh" it (reinstall over the top with the same tool; your data is kept). AltStore can do the refresh automatically in the background when your phone and computer are on the same Wi-Fi. A paid developer account ($99/yr) gives one year. TrollStore installs don't expire at all but only work on certain iOS versions.

Method 1: Sideloadly (easiest)

A Windows or Mac app that signs and installs the IPA over a USB cable.

1

Get the pieces

  • Download Collectify's .ipa to your computer (button above).
  • Install Sideloadly from sideloadly.io.
  • On Windows, install iTunes and iCloud from Apple's own website (not the Microsoft Store versions), because Sideloadly needs their USB drivers.
2

Connect your iPhone

Plug it in with a cable, unlock it and tap Trust This Computer if asked.

3

Load the IPA

Drag Collectify-vX.Y.Z.ipa onto the Sideloadly window. Type your Apple ID email. (Using a spare Apple ID just for sideloading is a good habit.)

4

Press Start

Enter your Apple ID password when asked. Sideloadly sends it to Apple only, to get a signing certificate. If your account uses two-factor, type the code Apple sends.

5

Trust the app on the iPhone

Open Settings → General → VPN & Device Management (on older iOS: Profiles & Device Management), tap your Apple ID under Developer App, then Trust.

6

Turn on Developer Mode (iOS 16 and newer)

If Collectify says "Developer Mode required" when you open it: Settings → Privacy & Security → scroll to Developer Mode → On. The phone restarts and asks you to confirm.

7

Open Collectify

Allow Camera (scanner and trade QR) and, for in-person trades, Local Network. The first launch unpacks the catalog.

Every 7 days: repeat steps 2 to 4 with the same Apple ID. Because it's the same app and the same ID, it installs over the old copy and keeps your data.

Method 2: AltStore (refreshes itself)

Install AltServer on your computer once; it keeps the app signed in the background.

1

Install AltServer and AltStore

Follow the official guide at altstore.io (Windows needs iTunes and iCloud from Apple's website, as above). In short: run AltServer, choose Install AltStore → your iPhone, sign in with your Apple ID.

2

Trust AltStore

Settings → General → VPN & Device Management → your Apple ID → Trust. Turn on Developer Mode if asked.

3

Get the IPA onto the iPhone

On the iPhone, open this page in Safari and download Collectify-vX.Y.Z.ipa. Then tap Share (or open it from Files → Downloads) and choose Open in AltStore, or open AltStore → My Apps → + and pick the file.

4

Wait for it to finish

AltStore signs and installs it. Then open Collectify from the home screen.

5

Keep it refreshed

  • Leave AltServer running on your computer, on the same Wi-Fi as your phone.
  • AltStore refreshes apps automatically a day or so before they expire. You can also open AltStore → My Apps → Refresh All.
  • A free Apple ID can have 3 sideloaded apps at once, and AltStore counts itself.

Method 3: TrollStore (no expiry)

Only works on specific iOS versions (roughly iOS 14.0 to 16.6.1 and 17.0). Check the TrollStore project to see whether yours is supported before trying.

1

Install TrollStore for your iOS version

Follow the instructions on the TrollStore project's own page. If your version isn't supported, use Method 1 or 2.

2

Download the IPA in Safari and share it to TrollStore

Tap the downloaded file → Share → TrollStore → Install. The signature doesn't expire, so there's nothing to refresh.

Updating on iPhone

Your data is kept as long as you install the new IPA over the old app with the same Apple ID.

1

See if there's something newer

In the app tap ℹ️ → Check for updates. On iPhone the About panel also shows how long this install's signature has left (when installed with Sideloadly or AltStore).

2

Download the new IPA and sideload it again

Use the same method and the same Apple ID you used the first time. Don't delete the app first: deleting an app on iOS removes its data.

If something goes wrong (iPhone)

"Untrusted Developer" when I open the app

Settings → General → VPN & Device Management → tap your Apple ID → Trust.

The app opens and immediately closes, or says it can't be opened

Usually the 7-day signature ran out. Sideload it again (Method 1 or 2) with the same Apple ID. Also check Developer Mode is on (iOS 16+).

"Developer Mode" doesn't appear in Settings

It only shows up after you've sideloaded an app. Install Collectify, then look in Settings → Privacy & Security again.

Sideloadly says my Apple ID has too many certificates / the app limit was reached

Free Apple IDs can have 3 active sideloaded apps and a limited number of certificates per week. Remove an old sideloaded app, or wait a few days, or use a different Apple ID.

Sideloadly or AltServer can't see my iPhone (Windows)

Install iTunes and iCloud from Apple's website (not the Microsoft Store), reconnect the cable, and tap Trust on the phone.

Trades don't work / "Local Network" is blocked

iPhone asks permission once. Settings → Collectify → Local Network → On. Both phones must be on the same Wi-Fi.

Notifications for reminders don't show

Settings → Notifications → Collectify → Allow. The app asks the first time you turn a reminder on.

Is it safe to give my Apple ID to Sideloadly or AltStore?

Both talk to Apple's own servers to get a free developer certificate; that's how Apple's developer program works. Many people use a separate Apple ID just for this. We never see your Apple ID or password: the IPA is the same unsigned file for everyone.

Check your file is genuine

Every release publishes a SHA-256 checksum for each file. If yours doesn't match, delete it and download again from this site or the GitHub releases page.

On Windows

Get-FileHash .\Collectify-vX.Y.Z.apk -Algorithm SHA256

On Mac or Linux

shasum -a 256 Collectify-vX.Y.Z.ipa   # or sha256sum

A checksum only proves the file matches what we published. It can't tell you anything about a copy from somewhere else.
