What you get

The whole hobby loop in one app

Find the card, file it, value it, show it off, swap it. The features page has the details; these are the headlines.

📷

Scanner

Point the camera at a card. On-device OCR reads it, checks the words against real card names and tells you how sure it is, or admits it couldn't read it.

📔

Binders

Page-by-page binders with value, search, sleeves and covers you design with your own cards and stickers.

💲

Prices

Market prices for around half a million cards and products, adjusted for condition. Estimates from tcgcsv.com (TCGplayer data), never offers.

🤝

In-person trading

Scan a QR on the same Wi-Fi and both phones see one live trade. Nothing moves until both sides agree.

⛏️

Treasure Box

Mine coins, claim a booster pack from any set of any game, rip it open and chase the rare pulls. Prestige for badges and new features.

🏝️

Island Care

A small 3D island to look after, sharing coins with the Treasure Box. No pet ever dies.

The same app on both phones

Every release has an Android .apk and an iPhone .ipa, built from the same web interface. The iPhone's on-device server is a Swift port of the Android one, tested against answers recorded from it.

Private by design

Your collection lives in a database on your phone. No accounts, no ads, no tracking. The only network use is prices, card pictures and the update check, when you ask for them.

Get it

Installing takes about two minutes

Collectify isn't in the Play Store or App Store yet, so you install the file yourself. The install page walks through every step and what to do if something goes wrong.

🤖 Android

Download the .apk, allow installs from your browser, tap it. Android 8.0 or newer. Updates install over the old version and keep your data.

📱 iPhone and iPad

Install the .ipa with AltStore, Sideloadly or TrollStore. A free Apple ID works; the app then needs a refresh once a week. iOS 15 or newer.
