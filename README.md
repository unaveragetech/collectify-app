# Collectify (Android) - test builds

Debug APK builds of the Collectify Android app (a WebView shell around the
[Collectify](https://github.com/unaveragetech/collectify) web app - card
scanning/OCR, binders, wishlist, price tracking across every TCG on
tcgcsv.com) for sideloading onto a test device.

Grab the latest APK from [Releases](../../releases).

Not signed for the Play Store - debug-signed only, for direct install.
